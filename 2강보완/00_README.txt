2회차 · 프로젝트 기반 업무 비서와 보고서 자동 생성
실습 환경: ChatGPT 웹의 Projects. 별도 설치·API 없이 기본 실습을 진행합니다.

실습 순서 (교안 페이지와 일치)
1. 7쪽: ChatGPT에서 새 프로젝트 '가온센터 업무 비서 실습'을 만듭니다. 8·11쪽: 설정 → 지침을 확인합니다.
2. 11쪽: 프로젝트 오른쪽 ··· → 프로젝트 설정의 지침에 02_작성규칙_v1.txt 본문을 붙여 넣습니다.
3. 10·12쪽: 프로젝트의 소스 → 소스 추가에서 03_센터운영규정_v1.txt와 05_보고서양식.txt를 등록합니다.
4. 19쪽: 등록한 규정의 정원·요금과 보고서 양식 순서를 묻고 11_결과확인.txt의 자료 확인란에 기록합니다.
5. 21~23쪽: 04_문의목록.txt의 Q1을 실행하고 저장된 지침·파일을 다시 확인합니다.
6. 26~32쪽: 04_문의목록.txt의 Q1~Q5를 v1에서 모두 시험하고 11_결과확인.txt에 기록합니다. 이후 프로젝트 지침을 08_작성규칙_v2.txt로 교체해 Q1~Q5를 동일하게 재시험합니다.
7. 34쪽: 조건을 바꾼 추가 질문을 새 대화에서 시험합니다.
8. 38~51쪽: 06_주간실적_A.txt와 07_업무메모_A.txt를 새 대화에 첨부하고 1주차 보고서를 검증·저장합니다.
9. 54~58쪽: 09_주간실적_B.txt와 10_업무메모_B.txt를 별도의 새 대화에 첨부하고 2주차 보고서를 검증·저장합니다.
10. 60~61쪽: 15_내업무설계.txt로 내 업무에 적용합니다. 실제 업무자료가 없으면 가온센터 사례로 두 번 실행하고 비교합니다.
11. 63쪽: 17_Plugins확장실습.txt를 이용해 업무 앱을 탐색하고 기능·권한·가상 요청문을 기록합니다. 개인 정보 조회나 연결은 필수가 아닙니다.

자료 구분
프로젝트 지침: 02 작성규칙 v1을 먼저 입력하고 08 v2로 교체합니다.
프로젝트 고정 파일: 03 운영규정, 05 보고서 양식.
대화별 입력: A는 06·07, B는 09·10입니다. 주차별 자료를 혼합하지 않습니다.
검증: 04 문의목록, 11 결과확인, 13·14 보고서예시를 사용합니다.
요청문: 12 복사용요청을 사용합니다. 설계 양식: 15 내업무설계를 사용합니다.

주의
모든 기관·담당자·날짜·실적은 교육용 가상 자료입니다.
완료는 해당 날짜 접수 중 완료 건수입니다. 이전 주 이월 건과 메모의 주차 문의 건수를 더하지 않습니다.
실제 예약이나 외부 앱 작업이 완료되었다고 임의로 표현하지 않습니다.
파일 생성이 제한되면 보고서 본문을 완성하여 문서 편집기에서 저장합니다.
Plugins 확장은 가상 사례로 앱 기능·권한을 탐색합니다. 개인 일정 조회·연결은 하지 않습니다.

화면 기준: 수강생이 제공된 실제 ChatGPT 프로젝트 화면(2026-11-04)을 따릅니다. 설정 메뉴의 지침에 TXT의 규칙을 붙여 넣고, 소스 탭에는 참고파일을 추가합니다.

파일 입력 위치 요약
02·08: 프로젝트 설정의 지침에 차례대로 붙여 넣습니다.
03·05: 프로젝트의 소스에 추가합니다.
04: 채팅에 Q1~Q5 질문을 복사합니다.
06·07: A 주차 새 채팅에 첨부합니다.
09·10: B 주차 새 채팅에 첨부합니다.
11: 수강생이 텍스트 파일을 열어 결과를 기록합니다. 프로젝트 소스에 넣지 않습니다.
12: 복사용 질문 모음입니다. 챗봇에 업로드하는 자료가 아닙니다.
13·14: 정답 대조용 보고서 예시입니다.
15: 개인 업무 적용 양식입니다.
17: Plugins 확장 실습 기록용입니다.
